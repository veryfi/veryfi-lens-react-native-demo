# W-9

Cloud extract for `w9`. Android Full allows `W9`. iOS model presence is **Unconfirmed**. Same Full binary as [w2.md](w2.md); only the document type changes.

## Permissions

Camera. Photo library for gallery. Backups off.

## Present

```javascript
VeryfiLens.configureWithCredentials(credentials, settings, (ok) => {
  if (ok) VeryfiLens.showCamera();
});
```

## Do not

Set `"mobile"`. Combine W-2 and W-9 in one camera unless `showDocumentTypes` is true and support confirms both models. Do not invent a W-9 package name.
