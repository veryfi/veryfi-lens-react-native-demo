# W-2

Cloud extract for `w2` on the Full binary. Android Full allows `W2`. iOS model presence in the vendored xcframework is **Unconfirmed**. If iOS does not detect a W-2, ask support whether this framework build includes that model. Do not add a W-2 pod from the host.

## Permissions

Camera. Photo library because gallery is on. Backups off.

## Settings

```javascript
const settings = {
  ignoreRemoteSettings: true,
  backupDocsToGallery: false,
  backupDocsToiCloud: false,
  moreSettingsMenuIsOn: false,
  moreMenuIsOn: false,
  autoCaptureOtherIsOn: false,
  showNoDocumentDetectedWarning: false,
  dictateIsOn: false,
  locationServicesIsOn: false,
  glareDetectionIsOn: false,
  enableScreenshots: true,

  dataExtractionEngine: 'api',
  documentTypes: ['w2'],
  showDocumentTypes: false,
  autoCaptureIsOn: false,
  stitchIsOn: false,
  galleryIsOn: true,
  browseIsOn: true,
  autoRotateIsOn: true,
  cleanBorderIsOn: true,
  returnStitchedPDF: true,
};
```

`browseIsOn` is the More-menu row and stays hidden while `moreMenuIsOn` is false. Use `showDocumentBrowser()` when Files is the entry point.

## Present

```javascript
VeryfiLens.configureWithCredentials(credentials, settings, (ok) => {
  if (ok) VeryfiLens.showCamera();
});
```

## Do not

Set `"mobile"`. Treat W-2 as Any-Documents unless support says the account uses an `any_document` template instead. Lite cannot scan W-2, and this plugin is not Lite.
